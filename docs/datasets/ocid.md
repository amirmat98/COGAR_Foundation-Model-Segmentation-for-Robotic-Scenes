# Dataset: OCID

## Summary

OCID is used as an external real-world RGB-D clutter dataset for robustness
testing. It is not generated by this project.

## Local Path

Current local copy:

```text
/mnt/Info/COGAR_DATASETs/OCID-dataset
```

Default repo path for another user:

```text
Datasets/OCID
```

Users may store it elsewhere and update `configs/datasets.yaml`.

## Contents

Expected top-level folders:

```text
ARID10/
ARID20/
YCB10/
```

Sequence folders contain matching `rgb`, `label`, `depth`, and `pcd` folders.

Current local scan:

- RGB frames: 2390
- Label frames: 2390
- Depth frames: 2390
- Point clouds: 2390

## Source

Download OCID from the public distribution associated with:

Markus Suchi, Timothy Patten, David Fischinger, Markus Vincze, "EasyLabel: A
Semi-Automatic Pixel-wise Object Annotation Tool for Creating Robotic RGB-D
Datasets", arXiv:1902.01626.

https://arxiv.org/abs/1902.01626
