# COGAR-SimRobotics-500 Dataset Release Workflow

This document explains how to package the frozen simulated dataset for sharing
without committing raw images, masks, or archives to Git.

The release package is for the Task 1 simulated dataset only:

```text
data/cogar_sim_500_final/
data/yolo_cogar_sim_500_final/
```

OCID is not included. OCID is an external dataset used for the separate massive
robustness benchmark, with compact outputs documented in
`docs/ocid_massive_benchmark_report.md`.

## What Gets Packaged

| Release asset | Source folder | Purpose |
|---|---|---|
| `COGAR-SimRobotics-500_dataset.tar.gz` | `data/cogar_sim_500_final/` | Full frozen 500-image benchmark with RGB images, masks, annotations, metadata, and splits. |
| `COGAR-SimRobotics-500_yolov8seg_export.tar.gz` | `data/yolo_cogar_sim_500_final/` | YOLOv8-seg training/export format derived from the frozen dataset. |
| `SHA256SUMS.txt` | generated by the packaging script | Checksum verification for downloaded assets. |
| `RELEASE_NOTES_TEMPLATE.md` | generated by the packaging script | Text to paste into the GitHub Release description. |

Do not include:

- `data/cogar_sim_500/`, because it is the working/candidate generation area.
- `data/cogar_sim_500_v2/`, because it is an older intermediate version.
- OCID, because it is external and distributed separately.
- `checkpoints/`, because model weights are separate dependencies.
- `outputs/`, because compact benchmark results are tracked in the repository.

## One-Command Packaging

Run this from the repository root:

```bash
bash scripts/dataset/package_release_datasets.sh
```

The default output directory is:

```text
/tmp/cogar_dataset_release
```

The script validates the frozen dataset before archiving and checks that the
final index has the expected counts:

```text
images: 500
objects: 4,471
```

## Dry Run

Use a dry run before creating large archives:

```bash
bash scripts/dataset/package_release_datasets.sh --dry-run
```

This checks the required folders and prints the dataset category/challenge
counts without writing archives.

## Custom Output Directory

To write the release assets somewhere else:

```bash
bash scripts/dataset/package_release_datasets.sh \
  --output-dir /tmp/cogar_dataset_release
```

To overwrite old archives:

```bash
bash scripts/dataset/package_release_datasets.sh --force
```

To package only the main dataset and skip the YOLO export:

```bash
bash scripts/dataset/package_release_datasets.sh --skip-yolo
```

## Upload To GitHub Release

Create a GitHub Release with:

| Field | Suggested value |
|---|---|
| Tag | `v1.0-cogar-sim-dataset` |
| Title | `COGAR-SimRobotics-500 Dataset Release` |
| Assets | all files in `/tmp/cogar_dataset_release` |
| Description | contents of `RELEASE_NOTES_TEMPLATE.md` |

Do not commit the `.tar.gz` files to Git. GitHub Release assets are the correct
place for these files.

## Reviewer Extraction

After downloading the release assets, a reviewer can extract them from the
repository root:

```bash
mkdir -p data
tar -C data -xzf COGAR-SimRobotics-500_dataset.tar.gz
tar -C data -xzf COGAR-SimRobotics-500_yolov8seg_export.tar.gz
```

Then verify:

```bash
sha256sum -c SHA256SUMS.txt
test -f data/cogar_sim_500_final/annotations/sim_robotic_scenes_index_final_filtered.csv
test -d data/cogar_sim_500_final/rgb
test -d data/cogar_sim_500_final/instance_masks/final
test -f data/yolo_cogar_sim_500_final/cogar_sim_500_yolov8seg.yaml
```

## Windows Extraction

On Windows PowerShell from the repository root:

```powershell
New-Item -ItemType Directory -Force data
tar -C data -xzf COGAR-SimRobotics-500_dataset.tar.gz
tar -C data -xzf COGAR-SimRobotics-500_yolov8seg_export.tar.gz
```

Then check:

```powershell
Test-Path data\cogar_sim_500_final\annotations\sim_robotic_scenes_index_final_filtered.csv
Test-Path data\cogar_sim_500_final\rgb
Test-Path data\cogar_sim_500_final\instance_masks\final
Test-Path data\yolo_cogar_sim_500_final\cogar_sim_500_yolov8seg.yaml
```
